# Warm Architectural Clinical V3

Operate-mode design contract for the existing server-rendered CI4 application. Visual authority: Owner-supplied `new-ui-ux/denta-warm-ui-v3`; its identity board is reference only. The kit remains unchanged in the original checkout.

Use forest espresso navigation, travertine canvas, sandstone panels, pine primary actions and restrained terracotta accents. Inter and Noto Sans Arabic follow the supplied reference. Shared tokens and accessible focus rules live in `public/assets/css/warm-clinical.css`; core workspace composition in `warm-workspaces.css`; secondary structures and theme in `warm-secondary-layout.css` and `warm-secondary.css`. The cached secondary structure preserves existing layout mechanics, with legacy decoration removed.

Recompose clinic tasks around a compact command header, meaningful metrics, primary workspace and contextual details. Use existing drawers for contextual forms and full pages for complex work. Tables remain tables with mobile overflow inside their own region. Arabic uses actual translations, logical spacing and RTL navigation; identifiers and amounts preserve their existing formatting. Never invent patient facts or simulated success.

Native odontogram SVG/rendering/snapshots, signed contract contents, business services, permissions and finance calculations are outside this visual contract. Existing navigation and form contracts remain authoritative. Unsupported prototype operations do not become capabilities. All optional switches retain their disabled state.

Motion is limited to short navigation transitions and existing controls, with reduced-motion handling. Keep keyboard focus visible, mobile navigation focus contained and Escape restorative. No new UI framework or dependency. Asset loading must follow actual workflow requirements.

See [acceptance record](docs/UI_V3_ACCEPTANCE.md) for evidence, curated screenshots and remaining visual acceptance. This is a draft development delivery, not deployment authorization.


Architectural components: `v3-flow-forms.css`, scoped `v3-support-views.css`, `v3-control-plane.css`, touch-first `v3-clinical-kiosk.css` and `v3-inventory-forms.css`. `v3-chart-chrome.css` styles outer screen chrome only, never SVG/snapshots. Screen-only links protect print output. Replace obsolete markup instead of stacking specificity overrides.
