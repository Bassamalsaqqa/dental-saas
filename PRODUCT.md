# Denta+

## Platform
web

## Confirmed product truth
Arabic/English multi-tenant dental clinic operations on CodeIgniter 4, PHP, MySQL/MariaDB and existing server-rendered views. Reception schedules visits and registers patients; clinicians review charts, examinations, treatment, prescriptions and evidence; finance/inventory staff use existing ledgers and stock workflows; owners manage clinic governance; Control Plane operators have separate platform authority; kiosk users have a privacy-scoped check-in task.

## Authority and preservation
The Owner-provided DentaPlus_V4_Master_Redesign_Codex_Prompt.md is the current presentation brief. Production-derived release 89352fd is the verified Git source baseline; current live installation was not contacted during this nonproduction campaign. Original checkout, V3 branch/gallery, customer records, native chart/snapshots, signed and financial histories, tenant/security contracts and proprietary/third-party licenses are protected. All optional features stay OFF. No migrations, production writes, merge or deployment. No automatic delegation.

## Scope
Replace the presentation system and workflow composition across existing routes, not business semantics. Existing APIs/services own all facts and mutations. Read-only adapters are permitted only when canonical, tenant/role scoped and bounded. Unresolved medical alert assessment semantics, insurance/tax/compensation rules and new integrations are separate domain decisions.
